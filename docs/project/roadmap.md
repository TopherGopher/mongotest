# Roadmap

mongotest is being reworked into a smaller core that depends only on the
official MongoDB driver, without breaking today's calls. The work is planned
and tracked in GitHub issues;
[#48](https://github.com/TopherGopher/mongotest/issues/48) lists them in
order.

[What's changing](../changing/index.md) describes the parts that are already
written.
